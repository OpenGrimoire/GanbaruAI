# Project operations

These documents describe maintainer procedures and intended repository policy.

- [Release process](release/README.md): branch promotion, validation, draft release inspection, and publication.
- [Signing](release/signing.md): updater, Android, package repository, and AUR credentials.
- [Distribution](release/distribution.md): updater feeds, Linux repositories, AUR, and recovery boundaries.
- [Repository policy](repository-policy.md): normative GitHub rulesets and protected-environment settings.
- [Testing](../testing/README.md): local validation and test-selection policy.
- [Contributing](../../CONTRIBUTING.md): contributor workflow.

Operational documents are normative unless they are explicitly labelled as an observation or a drift report. Live settings that are weaker than the intended policy are configuration drift, not a reason to weaken the documentation silently.
