# AI coordination boundary

AI coordination turns an explicit project assignment into a bounded provider run. It does not create a privileged manager identity, general vault agent, or authority outside the organizational model.

## Resolution

Before work starts, Rust resolves:

- Requesting conversation and participant.
- Project and task or explicit objective.
- Stable AI teammate identity when one is invoked.
- Authorized working folder or private scratch generation.
- Bounded context package.
- Effective access and confirmation policy.
- Provider, model, interaction mode, and capability.
- Time, token, cost, and delegation budgets where configured.
- Review and result destination.

Provider-native trust, a previous run, or shell availability cannot widen any resolved value.

## Structured delegation

Delegation creates a separate typed child assignment. It records the parent, objective, target, authority subset, budget, expected result, and review path. Provider-internal hidden subagents are not treated as organizational teammates unless their work is represented through this application-owned structure.

Parallel assignments remain independently cancellable and reviewable. A failed child assignment does not silently broaden another assignment to compensate.

## Context

Context packages include only selected messages, project records, Notes, tasks, attachments, and working-folder references permitted for the assignment. They are reproducible enough for later review and never scan the complete vault by default.

## Results

Provider events normalize into the run timeline. Material outcomes, exceptions, decisions, and proposed canonical changes return to the owning conversation and project review flow. Low-level tool narration stays inspectable without overwhelming shared channels.

## Human control

Destructive, external, credential, security-sensitive, or broad-scope actions retain their typed confirmation boundary. Budgets, quiet periods, cancellation, and exception reporting support sustainable supervision rather than continuous monitoring.
